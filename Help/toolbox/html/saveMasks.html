Help v. 2.0

Descrição

O algoritmo salva as configurações de máscaras aplicadas nas camadas de rótulos e exporta as informações para um arquivo .json.

Parâmetros

• Selecionar o arquivo para salvar → Definir um caminho para salvar o arquivo .json.

Exemplo

Modelagem EDGV 3.0 Topo na escala de 1:25.000

• Selecionar o arquivo para salvar → "C:/caminho/mascaras.json" Atenção: Ao dar um nome ao arquivo lembrar de colocar a extensão ".json".
