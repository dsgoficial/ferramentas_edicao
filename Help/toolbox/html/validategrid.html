Help v. 2.0

Descrição

O algoritmo valida o grid e os pontos de número de coordenada gerados contra um grid de referência calculado internamente a partir da moldura e da escala, identificando linhas ausentes, extras ou incorretas e pontos faltantes, extras ou com atributos errados.

Parâmetros

• Selecione a camada de moldura → Indicar a camada que contém a moldura do produto cartográfico. • Selecione a escala de edição → Indicar a escala do produto cartográfico. • Selecione a camada de grid a ser validada → Indicar a camada de linhas do grid gerado (padrão: edicao_grid_edicao_l). • Selecione a camada de pontos a ser validada → Indicar a camada de pontos de número do grid (padrão: edicao_grid_numerico_p). • Tolerância de deslocamento dos pontos (metros) → Distância máxima admitida entre um ponto existente e a posição de referência para que seja considerado correto. • Erros do Grid → Camada de linhas resultante com as diferenças encontradas entre o grid existente e o de referência. Por padrão gera camada temporária. • Erros dos Pontos → Camada de pontos resultante indicando pontos faltantes, extras ou com atributos incorretos. Por padrão gera camada temporária.

Exemplo

Modelagem EDGV 3.0 Topo na escala de 1:25.000

• Selecione a camada de moldura → aux_moldura_a • Selecione a escala de edição → 1:25.000 • Selecione a camada de grid a ser validada → edicao_grid_edicao_l • Selecione a camada de pontos a ser validada → edicao_grid_numerico_p • Tolerância de deslocamento dos pontos (metros) → 1,0 • Erros do Grid → Criar camada temporária • Erros dos Pontos → Criar camada temporária

Aplicação

Camadas de erro geradas indicando divergências entre o grid existente e o de referência.
