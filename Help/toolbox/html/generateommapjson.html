Help v. 2.0

Descrição

Gera o arquivo JSON de entrada para exportação individual da Carta Ortoimagem OM. O polígono da OM é extraído automaticamente da feição selecionada e reprojetado para EPSG:4326. Cada atributo pode ser preenchido manualmente ou mapeado a partir de um campo da tabela de atributos da camada.

Parâmetros

• Camada com o polígono da OM → Camada vetorial de polígonos. Use "Feições selecionadas" para processar apenas uma feição específica. • Nome da OM / ↳ ou campo → Nome completo da Organização Militar. Pode ser digitado ou mapeado de um campo da camada (o campo tem prioridade). • Imagem do brasão da OM → Caminho do arquivo PNG/JPG do brasão da OM (suporta caminhos de rede UNC). • Imagem do brasão da subordinação → Caminho do arquivo PNG/JPG do brasão da subordinação. • Subordinação 1 / Subordinação 2 → Cadeia de subordinação da OM (opcionais). • Altitude → Altitude da OM em metros (ex: 9 m). • Endereço da OM → Endereço completo da OM. • URL da imagem de fundo → URL do serviço XYZ de imagem de fundo (padrão: Bing Aerial). • Ortoimagem (.tif) → Caminho do arquivo raster da ortoimagem gerada por RPA. • EPSG da ortoimagem → Código EPSG do SRC da ortoimagem (padrão: 4326). • Nome do executor das fases → Nome da organização executora (padrão: 1º CGEO). • Ano do Imageamento / PDI / Edição → Anos de execução de cada fase. • Sensores (JSON) → Lista de sensores em formato JSON. Padrão: WorldView-2 + CMOS RPA. • Data de criação → Data de criação do produto no formato DD/MM/AAAA. • PEC Planimétrico / Altimétrico → Padrão de Exatidão Cartográfica (ex: A***). • Datum vertical → Datum vertical utilizado (padrão: Imbituba - Santa Catarina). • Origem dos dados altimétricos → Fonte dos dados altimétricos (padrão: GLO-30). • Dados de terceiros → Lista JSON de fontes de dados de terceiros. • Arquivo JSON de saída → Caminho onde o arquivo JSON será salvo.

Exemplo

Carta Ortoimagem OM - 63º Batalhão de Infantaria

• Camada com o polígono da OM → om_poligonos (feição do 63BI selecionada) • Nome da OM → 63º Batalhão de Infantaria • Imagem da OM → \\servidor\brasoes\63BI.png • Ortoimagem → \\servidor\dronedb\63bi_florianopolis.tif • Arquivo JSON de saída → C:\json\63bi_florianopolis.json

Aplicação

JSON gerado pronto para uso no serviço de exportação da Carta Ortoimagem OM.
