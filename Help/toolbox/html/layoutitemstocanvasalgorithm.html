Help v. 2.0

Descrição

O algoritmo cria uma camada vetorial de polígonos com os limites dos elementos de um layout de impressão (mapas, formas, imagens e rótulos), reprojetados para o sistema de coordenadas do mapa de referência. A camada resultante é carregada diretamente no canvas do QGIS com estilo próprio.

Parâmetros

• Input layout → Indicar o layout de impressão do qual os elementos serão extraídos. • Mapa de referência → Indicar o item de mapa do layout que será usado como referência para a transformação de coordenadas. Os demais elementos são posicionados relativamente a ele.

Exemplo

• Input layout → Layout_MI_2794-3-SE • Mapa de referência → Mapa principal do layout

Aplicação

Camada vetorial com os limites dos elementos do layout projetados sobre o canvas.
