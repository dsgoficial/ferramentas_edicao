Help v. 2.0

Descrição

A rotina altera o atributo 'sobreposto' da camada de limite especial, caso essas camadas tenham interseção com uma camada a ser sobreposta. As entradas são do tipo linha e o atributo a ser alterado é o "sobreposto" da camada de limite especial. A classificação usa apenas feições de referência visíveis; trechos coincidentes com a borda externa da moldura são removidos (bordas internas entre folhas são preservadas). As feições novas são preparadas antes da substituição — a rotina é reexecutável sem duplicar e reporta as contagens no resultado.

Parâmetros

• Selecionar a camada de moldura → Indicar a camada que contém a(s) moldura(s) do projeto. • Selecionar a camada de limite especial linha → Indicar a camada que contém o(s) limite(s) especial(is) com geometria do tipo linha. • Selecione a camada de limite especial área → Indicar a camada que contém o(s) limite(s) especial(is) com geometria do tipo área. • Selecione a camada de trecho de drenagem → Indicar a camada que contém os trechos de drenagem. • Selecione a camada de via de deslocamento → Indicar a camada que contém as vias de deslocamento. • Selecione a camada de ferrovia → Indicar a camada que contém as ferrovias.

Modelagem EDGV 3.0 Topo na escala de 1:25.000
