Help v. 2.0

Descrição

O algoritmo aplica os estilos de edição conforme a modelagem selecionada e realiza o ordenamento das camadas em conformidade com o padrão de impressão.

Parâmetros

• Selecione o tipo de produto → Indicar o produto conforme a modelagem utilizada. • Selecione a escala de edição → Indicar a escala de edição do produto. • Grupo → Indicar qual grupo (conforme painel do QGIS de camadas) os estilos serão aplicados. • Deseja exibir curvas auxiliares → Permite a visualização de curvas de nível auxiliares. Parâmetros Avançados • Definir equidistância fora do padrão → Equidistância diferente do previsto para a escala do trabalho, indicada em metros. • Utilizar estilo de impressão → Carrega os estilos que serão impressos no lugar dos estilos de edição, utilizado para verificar eventuais incorreções antes da importação final.

Exemplo

Modelagem EDGV 2.0 na escala de 1:25.000

• Selecione o tipo de produto → Carta Topográfica 2.0. • Selecione a escala de edição → 1:25.000 • Grupo → doc_topo_20 • Deseja exibir curvas auxiliares → Não • Definir equidistância fora do padrão → Not set • Utilizar estilo de impressão → Não

Aplicação

Camadas ordenadas e com os estilos de edição carregados.
