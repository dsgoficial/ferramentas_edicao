Help v. 2.0

Descrição

Gera em lote os arquivos JSON de entrada para exportação da Carta Ortoimagem SARP. Cada feição da camada gera um arquivo JSON separado. Os atributos individuais de cada OM (nome, imagens, endereço, etc.) são lidos obrigatoriamente de campos da tabela de atributos. Os dados comuns a todas as OMs (fases, sensores, informações técnicas) são configurados uma única vez e aplicados a todos os JSONs gerados.

Parâmetros

Dados por feição (campos da camada):
• Camada com os polígonos das OMs → Camada vetorial de polígonos com uma feição por OM. Use "Feições selecionadas" para processar um subconjunto. • Campo: Nome do arquivo de saída → Campo usado para nomear cada JSON gerado (ex: campo "sigla" → "63bi.json"). • Campo: Nome da OM → Campo com o nome completo de cada OM. • Campo: Imagem do brasão da OM → Campo com o caminho do arquivo PNG do brasão de cada OM. • Campo: Imagem do brasão da subordinação → Campo com o caminho do arquivo PNG da subordinação. • Campo: Subordinação 1 / 2 → Campos com a cadeia de subordinação (opcionais). • Campo: Altitude → Campo com a altitude de cada OM (ex: "9 m"). • Campo: Endereço → Campo com o endereço de cada OM. • Campo: Ortoimagem → Campo com o caminho do arquivo TIF da ortoimagem de cada OM. • Campo: EPSG da ortoimagem → Campo com o EPSG da ortoimagem (opcional; se vazio, usa o valor padrão configurado abaixo).
Dados comuns a todas as OMs:
• URL da imagem de fundo → URL do serviço XYZ (padrão: Bing Aerial). • EPSG padrão da ortoimagem → Usado quando o campo de EPSG não for mapeado (padrão: 4326). • Nome do executor das fases → Nome da organização executora (padrão: 1º CGEO). • Ano do Imageamento / PDI / Edição → Anos de execução de cada fase. • Sensores (JSON) → Lista de sensores em formato JSON aplicada a todas as OMs. • Data de criação → Data de criação no formato DD/MM/AAAA. • PEC Planimétrico / Altimétrico, Datum vertical, Origem altimétrica, Dados de terceiros → Informações técnicas aplicadas a todas as OMs. • Pasta de saída → Diretório onde os arquivos JSON serão salvos.

Exemplo

Lote da 14ª Brigada de Infantaria Motorizada

• Camada → om_14bda (13 feições, uma por OM) • Campo: Nome do arquivo → "sigla" (ex: 63bi → 63bi.json) • Campo: Nome da OM → "nome_completo" • Campo: Imagem da OM → "caminho_brasao" • Campo: Ortoimagem → "caminho_orto" • Pasta de saída → C:\json\14bda\

Aplicação

JSONs gerados em lote para todas as OMs da camada, prontos para uso no serviço de exportação.
