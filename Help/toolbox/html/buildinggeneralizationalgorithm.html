Help v. 2.0

Descrição

O algoritmo generaliza feições pontuais de edificações com símbolos quadrados alinhados aos eixos, resolvendo conflitos espaciais (edificação-edificação, edificação-via e edificação-borda de massa d'água) por deslocamento iterativo. Quando o deslocamento não é suficiente, edificações genéricas são ocultadas (campo de visibilidade = 2) e edificações não genéricas com conflitos irresolvíveis são enviadas para a camada de flags para revisão manual. Atenção: O algoritmo edita a camada de edificações in-place. As alterações de geometria e visibilidade são aplicadas diretamente na camada de entrada.

Parâmetros

• Camada de edificações → Indicar a camada de edificações com geometria do tipo ponto que será editada in-place. • Camada de vias → Indicar a camada que contém as vias de deslocamento. Usada para construir a zona proibida. • Camada de massa d'água (opcional) → Indicar a camada de massa d'água. As bordas serão usadas como zona proibida adicional. • Camada de moldura (opcional) → Indicar a moldura do produto. Edificações fora da moldura são ignoradas. • Habilitar deslocamento → Quando marcado, aplica deslocamento iterativo para resolver conflitos. Quando desmarcado, opera apenas em modo de redução de densidade (somente conflitos entre edificações são considerados). • Campo de visibilidade → Atributo da camada de edificações que controla a visibilidade. Edificações com valor 2 são ignoradas; edificações genéricas com conflitos irresolvíveis recebem valor 2. • Tamanho do símbolo - lado do quadrado (metros) → Dimensão do símbolo de edificação em metros no terreno. • Espaçamento mínimo entre símbolos (metros) → Distância mínima de separação entre dois símbolos adjacentes. • Largura do símbolo de via (metros) → Largura da simbologia de via em metros, usada para calcular o buffer de zona proibida. • Deslocamento máximo (metros) → Distância máxima que uma edificação pode ser deslocada em relação à sua posição original. • Número máximo de iterações → Limite de iterações do processo de deslocamento. • Expressão para edificações genéricas → Expressão QGIS que identifica edificações de baixa prioridade (genéricas), que serão ocultadas preferencialmente em caso de conflito irresolvível. • Edificações não genéricas com conflitos irresolvíveis (flags) → Camada de saída com as edificações que não puderam ser resolvidas por deslocamento nem ocultação. Por padrão gera camada temporária.

Exemplo

Modelagem EDGV 3.0 Topo na escala de 1:25.000

• Camada de edificações → constr_edificacao_p • Camada de vias → infra_via_deslocamento_l • Camada de massa d'água (opcional) → cobter_massa_dagua_a • Camada de moldura (opcional) → aux_moldura_a • Habilitar deslocamento → Marcado • Campo de visibilidade → visivel • Tamanho do símbolo - lado do quadrado (metros) → 25,0 • Espaçamento mínimo entre símbolos (metros) → 2,0 • Largura do símbolo de via (metros) → 35,0 • Deslocamento máximo (metros) → 50,0 • Número máximo de iterações → 50 • Expressão para edificações genéricas → "tipo" in (0, 9999) • Edificações não genéricas com conflitos irresolvíveis (flags) → Criar camada temporária

Aplicação

Edificações deslocadas e/ou ocultadas para eliminar conflitos com vias e entre si.
