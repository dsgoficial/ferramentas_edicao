Descrição

O algoritmo define o atributo tamanho_txt dos trechos de drenagem nomeados conforme as tabelas do MTM, usando o comprimento TOTAL do rio dentro da moldura (trechos que se tocam e têm o mesmo nome são fundidos; homônimos desconexos são rios distintos). O tamanho calculado é propagado a TODOS os trechos que compõem o rio. Trechos com situação em polígono 2/3/4 usam a tabela de dentro de massa d'água; situação 1, nula ou a preencher usa a tabela de fora. Para Carta Ortoimagem o tamanho mínimo é 7. Trechos nomeados totalmente fora da moldura não são alterados e são contados no resultado.

Parâmetros

• Selecione a camada de trecho de drenagem → Indicar a camada que contém os trechos de drenagem. • Selecionar a camada de moldura → Indicar a camada que contém a(s) moldura(s) do projeto. • Selecione a escala de edição → Indicar a escala da Carta Topográfica. • Selecione o tipo de produto → Selecionar entre Carta Topográfica ou Carta Ortoimagem.

Exemplo

Modelagem EDGV 3.0 Topo na escala de 1:25.000

• Selecione a camada de trecho de drenagem → elemnat_trecho_drenagem_l • Selecionar a camada de moldura → aux_moldura_a • Selecione a escala de edição → 1:25.000 • Selecione o tipo de produto → Carta Topográfica

Aplicação

Atributo 'tamanho_txt' preenchido adequadamente.
